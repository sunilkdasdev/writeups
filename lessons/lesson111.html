Lesson 111: CAP Theorem Illustrated

Watch Video Lesson | April 12, 2021

Video Summary

CAP Theorem describes the tradeoffs in distributed systems between Consistency (C), Availability (A), and Partition tolerance (P). The theorem states you can only pick two. Mark illustrates these options using services and data examples.

The Three Options:

  • CP (Consistency + Partition Tolerance) - MongoDB, Cassandra (Strong), HBase
    When partitions occur: sacrifice availability for consistency
  • AP (Availability + Partition Tolerance) - Cassandra, CouchDB, DynamoDB
    When partitions occur: sacrifice consistency for availability
  • CA (Consistency + Availability) - Not possible with partitions
    Only works without network partitions (rare in practice)

Key Insight:

Network partitions WILL happen. So you must choose between CP or AP. There's no "CA" in real distributed systems.
