# Java Interview Questions and Answers (600+)

This document contains a comprehensive list of Java interview questions with concise 2-3 line answers, covering core Java, collections, multithreading, JVM, streams, and more.

---

## Core Java Concepts

1. **What is the difference between JDK, JRE, and JVM?**  
   JDK (Java Development Kit) includes JRE and development tools. JRE (Java Runtime Environment) provides libraries and JVM to run Java programs. JVM (Java Virtual Machine) executes Java bytecode.

2. **What is platform independence in Java?**  
   Java code is compiled to bytecode, which runs on any platform with a JVM. This "write once, run anywhere" capability makes Java platform-independent.

3. **What is the main() method in Java?**  
   The main() method is the entry point of a Java application. It must be public, static, void, and accept a String array as argument: `public static void main(String[] args)`.

4. **What are the primitive data types in Java?**  
   Java has 8 primitives: byte, short, int, long, float, double, char, boolean. They store simple values directly in memory.

5. **What is the difference between == and equals()?**  
   == compares object references (memory addresses) for objects, or values for primitives. equals() compares the actual content of objects, typically overridden in classes like String.

6. **What is the String pool?**  
   The String pool is a special memory region in heap where String literals are stored. When a new String literal is created, JVM checks the pool and reuses existing references if available.

7. **Is String immutable? Why?**  
   Yes, String objects are immutable. Once created, their values cannot be changed. This ensures security, caching, and thread safety. Any modification creates a new String.

8. **What is the difference between String, StringBuilder, and StringBuffer?**  
   String is immutable. StringBuilder is mutable and not thread-safe. StringBuffer is mutable and thread-safe (synchronized methods). Use StringBuilder for single-threaded string manipulation.

9. **What is the difference between final, finally, and finalize?**  
   final is a keyword used for variables (cannot reassign), methods (cannot override), and classes (cannot extend). finally is a block in exception handling that always executes. finalize() is a deprecated method called by GC before object destruction.

10. **What is method overloading and overriding?**  
    Overloading: multiple methods with same name but different parameters within same class (compile-time polymorphism). Overriding: subclass provides specific implementation of a superclass method (runtime polymorphism).

11. **Can we override a static method?**  
    No, static methods are class-level and cannot be overridden; they are hidden if a subclass defines a static method with the same signature.

12. **What is the difference between abstract class and interface?**  
    Abstract class can have both abstract and concrete methods, instance variables, constructors. Interface (pre-Java 8) had only abstract methods and constants. From Java 8, interfaces can have default and static methods; from Java 9, private methods.

13. **What is polymorphism?**  
    Polymorphism means "many forms". It allows objects of different classes to be treated as objects of a common superclass, with method behavior determined at runtime (dynamic method dispatch).

14. **What is encapsulation?**  
    Encapsulation is hiding internal state and requiring all interaction to be performed through methods. Achieved by making fields private and providing public getters/setters.

15. **What is a constructor?**  
    A constructor is a special method invoked when an object is created. It initializes the object. It has the same name as the class and no return type. If not defined, Java provides a default no-arg constructor.

16. **What is the first thing a constructor does?**  
    The first statement in a constructor must be either this() (to call another constructor) or super() (to call parent constructor). If not written, compiler inserts super() automatically.

17. **What is a default constructor?**  
    A default constructor is automatically generated by the compiler if no constructors are explicitly defined. It takes no arguments and calls super().

18. **What is a copy constructor?**  
    A copy constructor initializes an object using another object of the same class. It is used to create a deep copy. Example: `public Person(Person other) { this.name = other.name; }`

19. **What is the difference between deep copy and shallow copy?**  
    Shallow copy copies the object's references to other objects; deep copy creates copies of all referenced objects as well. Cloning in Java by default does shallow copy.

20. **What is the `this` keyword?**  
    `this` refers to the current object instance. It can be used to access instance variables, invoke current class methods, or call another constructor (this()).

21. **What is the `super` keyword?**  
    `super` refers to the immediate parent class instance. It is used to access parent class methods/fields and call parent class constructor.

22. **What are static variables and methods?**  
    Static members belong to the class rather than any instance. They are shared across all objects. Static methods cannot access non-static members directly.

23. **Can static methods access non-static variables?**  
    No, static methods cannot directly access non-static variables or methods because they exist without an instance.

24. **What is a static block?**  
    A static block is executed when the class is loaded, used for static initialization. Multiple static blocks run in order they appear.

25. **What is an instance initializer block?**  
    Instance initializer block runs before constructor each time an object is created. It is used to initialize instance variables common to all constructors.

26. **What is the difference between instance variable and local variable?**  
    Instance variables are declared in a class but outside methods, have default values, and exist as long as the object. Local variables are declared inside methods/blocks, must be initialized, and exist only during method execution.

27. **What is the `void` type?**  
    `void` is a keyword used to specify that a method does not return any value. It is not a primitive type but a placeholder.

28. **What is the `Void` class?**  
    `Void` is an uninstantiable placeholder class to hold a reference to the Class object representing the void keyword. Used in generics when you need to indicate void type.

29. **What is wrapper class?**  
    Wrapper classes (Integer, Double, Boolean, etc.) encapsulate primitive types in objects. Used in collections, generics, and when null is needed.

30. **What is autoboxing and unboxing?**  
    Autoboxing: automatic conversion of primitive to its wrapper (int → Integer). Unboxing: wrapper to primitive (Integer → int). Introduced in Java 5.

31. **What is a value-based class?**  
    Value-based classes (e.g., Optional, LocalDate) are immutable, have no accessible constructors, and are instantiated by static factory methods. They are candidates for primitive-like behavior in future Java.

32. **What is an anonymous class?**  
    An anonymous class is a local class without a name, defined and instantiated in a single expression. Used for quick implementations of interfaces or abstract classes.

33. **What is a lambda expression?**  
    Lambda expressions provide a concise way to implement functional interfaces using expression syntax. Example: `(a, b) -> a + b`. They enable functional programming in Java.

34. **What is a functional interface?**  
    A functional interface has exactly one abstract method. Can have multiple default/static methods. Examples: Runnable, Comparator. Can be annotated with @FunctionalInterface.

35. **What are the common functional interfaces in java.util.function?**  
    Predicate<T> (boolean test), Function<T,R> (apply), Consumer<T> (accept), Supplier<T> (get), UnaryOperator<T>, BinaryOperator<T>.

36. **What is method reference?**  
    Method reference is a shorthand for lambda calling an existing method. Types: static method (Class::staticMethod), instance method (object::instanceMethod), constructor (Class::new).

37. **What is the difference between `Predicate` and `Function`?**  
    Predicate takes one argument and returns boolean. Function takes one argument and returns a result of any type.

38. **What is a `Consumer`?**  
    Consumer represents an operation that accepts a single input and returns no result (void). Used in forEach, etc.

39. **What is a `Supplier`?**  
    Supplier represents a supplier of results, takes no argument but returns a value. Used in lazy generation or factory methods.

40. **What is type inference?**  
    Type inference is the compiler's ability to deduce type arguments from context. Enhanced with diamond operator (`<>`) and local variable type inference (`var`).

41. **What is `var` in Java?**  
    `var` is a reserved type name introduced in Java 10 for local variable type inference. The compiler infers the type from the initializer. Cannot be used for fields, method parameters, or return types.

42. **What is an expression?**  
    An expression is a construct made up of variables, operators, and method invocations that evaluates to a single value. Examples: `a + b`, `methodCall()`.

43. **What is a statement?**  
    A statement forms a complete unit of execution. Types: assignment, if, for, while, return, etc. Statements often end with semicolon.

44. **What is a block?**  
    A block is a group of statements enclosed in curly braces {}. It defines a scope.

45. **What is variable shadowing?**  
    Variable shadowing occurs when a variable declared within a certain scope has the same name as a variable in an outer scope, hiding the outer variable.

46. **What is variable capturing?**  
    A lambda or anonymous class can capture effectively final local variables from the enclosing scope. The variables must be final or effectively final (not reassigned).

47. **Why doesn't Java allow variable capturing of non-final variables?**  
    To avoid concurrency issues and maintain consistency; captured variables are copied, and mutability would cause inconsistencies.

48. **What does "effectively final" mean?**  
    A variable is effectively final if it is not reassigned after initialization, even if not declared final. Can be used in lambdas and anonymous classes.

49. **What is a `Record`?**  
    Records (Java 14+) are transparent carriers for immutable data. They automatically generate constructor, equals, hashCode, toString. Syntax: `record Point(int x, int y) {}`.

50. **What is a compact constructor in a record?**  
    A compact constructor omits parameters; it is used to validate or normalize data before assignment. After validation, fields are implicitly assigned.

51. **What is a `Sealed` class?**  
    Sealed classes (Java 15+) restrict which classes or interfaces may extend/implement them. Defined with `sealed` keyword and `permits` clause.

52. **How can you create a sealed type without `permits`?**  
    If subclasses are defined in the same compilation unit (nested within the sealed class), the `permits` clause can be omitted.

53. **What is a `Pattern Matching` for instanceof?**  
    Pattern matching (Java 16+) combines type check and variable declaration: `if (obj instanceof String s) { ... }`. No explicit cast needed.

54. **What is a guarded pattern?**  
    Guarded patterns (Java 17 preview) allow you to refine pattern matching with a boolean expression using `&&` in switch labels, e.g., `case String s && s.length() > 5`.

55. **What is a `Switch` expression?**  
    Switch expressions (Java 12+) return a value, use arrow syntax `->`, and must be exhaustive. Can be used with yield to return from a block.

56. **How does `switch` on `String` work?**  
    Java 7 introduced switching on String. Compiler generates code using hash codes for efficiency; it's syntactic sugar over if-else chains.

57. **When does a `switch` check for exhaustiveness?**  
    For switch expressions and pattern switches, the compiler ensures all possible cases are covered; otherwise, it throws an error.

58. **What is a text block?**  
    Text blocks (Java 13+) are multi-line string literals using triple quotes `"""`. They preserve formatting and eliminate need for escape sequences for newlines.

59. **What is an unnamed variable?**  
    Unnamed variables (Java 21 preview) are represented by underscore `_` and indicate that a variable is not used. Useful in try-with-resources, catch blocks, lambda parameters.

60. **What is a `final` class?**  
    A final class cannot be subclassed. Used for immutability and security (e.g., String, Integer).

61. **What is a `final` method?**  
    A final method cannot be overridden by subclasses. Ensures consistent behavior.

62. **What is a `final` field?**  
    A final field must be initialized exactly once (either inline or in constructor). After initialization, its value cannot change.

63. **What are static imports?**  
    Static import allows members (fields, methods) of a class to be used without class name. Example: `import static java.lang.Math.PI;` then use `PI` directly.

64. **What is a package?**  
    A package groups related classes and interfaces. It provides namespace management and access protection.

65. **What is a module?**  
    Module (Java 9+) is a set of packages with explicitly declared dependencies and exported packages via module-info.java. Encapsulation at JAR level.

66. **What is the module descriptor?**  
    module-info.java declares module name, requires other modules, exports packages, opens packages for reflection, provides services.

67. **What are preview features?**  
    Preview features are fully specified but not permanent language features, available for testing. Must be enabled with `--enable-preview` flag.

68. **What is JShell?**  
    JShell (Java 9) is a REPL tool for Java that evaluates declarations, statements, and expressions interactively.

69. **What is the difference between `Enum` and `Enumeration`?**  
    Enum is a type (enum) defining a fixed set of constants. Enumeration is an interface (deprecated) for iterating legacy collections like Vector.

70. **What is an enum?**  
    Enum defines a fixed set of named constants. They are implicitly final, can have fields, methods, constructors. All enums extend java.lang.Enum.

71. **Can enum have abstract methods?**  
    Yes, enum can declare abstract methods, and each constant must implement them. This allows constant-specific behavior.

72. **What is the ordinal of an enum?**  
    The ordinal() method returns the zero-based position of an enum constant in its declaration. However, relying on ordinal is not recommended as it can change.

73. **What is the difference between `Enum` and `EnumSet`?**  
    EnumSet is a specialized Set implementation for enum types, more efficient than HashSet. It stores bit masks internally.

74. **What is an annotation?**  
    Annotations provide metadata about code. They can be processed at compile-time or runtime via reflection. Common: @Override, @Deprecated, @FunctionalInterface.

75. **What is a meta-annotation?**  
    Meta-annotations are annotations applied to other annotations. Examples: @Target (where annotation can be used), @Retention (how long retained), @Documented, @Inherited.

76. **What is the `@FunctionalInterface` annotation?**  
    It indicates an interface is intended to be a functional interface. Compiler ensures it has exactly one abstract method.

77. **What is the difference between `@Override` and `@Overload`?**  
    @Override indicates a method overrides a superclass method. There's no @Overload annotation; overloading is not annotated.

78. **What is reflection?**  
    Reflection allows inspecting and manipulating classes, methods, fields at runtime. Used in frameworks (Spring, Hibernate). Can break encapsulation.

79. **What is the `Class` object?**  
    Every class loaded by JVM has a corresponding Class object representing it. Obtained via `.class`, `getClass()`, or `Class.forName()`.

80. **How can you get an instance of a `Class`?**  
    Using: `MyClass.class`, `obj.getClass()`, `Class.forName("fully.qualified.Name")`.

81. **What is a `MethodHandle`?**  
    MethodHandle (Java 7) is a typed, directly executable reference to a method, constructor, or field. More efficient than reflection, used with invokedynamic.

82. **What is a `VarHandle`?**  
    VarHandle (Java 9) is a reference to a variable (static field, instance field, array element) that supports atomic operations and memory access modes.

83. **What is the difference between `Class.forName()` and `ClassLoader.loadClass()`?**  
    `Class.forName()` initializes the class (runs static initializers). `ClassLoader.loadClass()` loads but does not initialize the class.

84. **What is a class loader?**  
    Class loader loads classes into JVM. Types: Bootstrap, Extension, System/Application. Custom class loaders can be created.

85. **What is a deserialization filter?**  
    Deserialization filter (Java 9+) allows restricting which classes can be deserialized to prevent security attacks.

86. **What is serialization?**  
    Serialization converts an object to a byte stream (e.g., for file storage or network). A class must implement Serializable interface. Deserialization reconstructs the object.

87. **What does `transient` mean?**  
    transient keyword prevents a field from being serialized. When object is serialized, transient fields are skipped and restored to default values.

88. **What is the difference between `Serializable` and `Externalizable`?**  
    Serializable is marker interface; JVM handles serialization. Externalizable requires implementing writeExternal and readExternal for custom serialization logic.

89. **What is the serialVersionUID?**  
    serialVersionUID is a unique identifier for serialized classes. Used during deserialization to verify sender and receiver have loaded compatible classes.

90. **What happens if serialVersionUID is not defined?**  
    JVM generates one automatically based on class details. If class changes, generated UID changes, causing InvalidClassException. Best practice to declare explicitly.

91. **What is a `Cloneable` interface?**  
    Marker interface indicating that a class can be cloned. Override `clone()` method (protected in Object) and make it public. Default is shallow copy.

92. **How to perform deep cloning?**  
    Override clone and call clone on mutable fields, or use copy constructors, or serialize-deserialize.

93. **What is the `Comparable` interface?**  
    Comparable defines natural ordering by `compareTo(T o)`. Used by Collections.sort and sorted collections. Must be consistent with equals.

94. **What is the difference between `Comparable` and `Comparator`?**  
    Comparable defines natural order (intra-class). Comparator defines external, custom order (inter-class). Comparator can be used when class not comparable or multiple orders needed.

95. **What is the `Comparator` interface?**  
    Comparator defines `compare(T o1, T o2)` to compare two objects. Used in sorting with custom order.

96. **How can you sort a `Collection`?**  
    Use `Collections.sort(list)` for natural order (elements must implement Comparable). For custom order: `Collections.sort(list, comparator)`.

97. **What does the `reversed()` method do?**  
    `reversed()` is a default method in Comparator that returns a comparator that reverses the order of the current comparator.

98. **What is a `vararg`?**  
    Varargs allow methods to accept a variable number of arguments of the same type. Syntax: `void method(String... args)`. Inside method, args is an array.

99. **What is a `native` method?**  
    Native method is implemented in platform-dependent code (C/C++) using Java Native Interface (JNI). Declared with `native` keyword, no body.

100. **What is the difference between `Error` and `Exception`?**  
    Error indicates serious system problems (e.g., OutOfMemoryError) not meant to be caught. Exception indicates conditions that a program should catch.

## Exception Handling

101. **What are checked and unchecked exceptions?**  
    Checked exceptions (except RuntimeException and subclasses) must be declared or caught. Unchecked exceptions (RuntimeException and subclasses) do not require explicit handling.

102. **What is the `throws` keyword?**  
    `throws` is used in method signature to declare that the method may throw one or more exceptions, delegating handling to caller.

103. **What is the `throw` keyword?**  
    `throw` is used to explicitly throw an exception object. Example: `throw new IllegalArgumentException("Invalid")`.

104. **What is the `try-catch-finally` block?**  
    try block encloses code that may throw exceptions. catch handles specific exceptions. finally block always executes (unless System.exit) used for cleanup.

105. **What is try-with-resources?**  
    try-with-resources (Java 7+) automatically closes resources (AutoCloseable) declared in try parentheses. Eliminates need for finally close.

106. **Can try-with-resources be used without catch/finally?**  
    Yes, try-with-resources can be used alone; resources are closed automatically after the try block.

107. **What is multi-catch?**  
    Multi-catch allows catching multiple exception types in one catch block separated by `|`. Example: `catch (IOException | SQLException e)`.

108. **What is exception chaining?**  
    Exception chaining allows an exception to wrap another exception. Constructors with `Throwable cause` preserve the original cause.

109. **What is the difference between `final` and `finally`?**  
    final is a modifier; finally is a block in exception handling.

110. **What is the `finalize()` method?**  
    finalize() is called by GC before object is collected (deprecated). Not reliable for cleanup.

111. **Why is finalization being deprecated?**  
    finalize has unpredictable timing, performance issues, and can cause problems with GC. Replaced by Cleaner (Java 9) and try-with-resources.

112. **What is a `Cleaner`?**  
    Cleaner (Java 9) provides a more reliable way to perform cleanup actions when an object becomes phantom reachable, using Cleanable and a background thread.

## Object-Oriented Programming

113. **What is the diamond problem in OOP?**  
    Diamond problem occurs in multiple inheritance when a class inherits from two classes with a common ancestor. Java avoids it by not allowing multiple inheritance of classes.

114. **How does Java solve diamond problem with interfaces?**  
    If a class implements two interfaces with default methods of same signature, the class must override the method to resolve conflict.

115. **What is composition?**  
    Composition is a design principle where a class contains references to other classes (has-a relationship). Prefer composition over inheritance for flexibility.

116. **What is aggregation?**  
    Aggregation is a weaker form of composition where the contained object can exist independently of the container.

117. **What is delegation?**  
    Delegation is when an object passes a task to another object. Often used to reuse functionality without inheritance.

118. **What is the difference between `is-a` and `has-a` relationship?**  
    is-a: inheritance (extends). has-a: composition/aggregation (field reference).

119. **What is cohesion?**  
    Cohesion measures how related the responsibilities of a class are. High cohesion is good (class focused on a single purpose).

120. **What is coupling?**  
    Coupling measures how much one class depends on another. Loose coupling is desirable (low dependency).

121. **What is an object?**  
    Object is an instance of a class, having state (fields) and behavior (methods). It represents a real-world entity.

122. **What is a class?**  
    Class is a blueprint/template for creating objects. It defines fields, methods, constructors, etc.

123. **What is the difference between an object and a reference?**  
    Object is an instance in memory. Reference is a variable that holds the memory address of an object. References can be reassigned, null.

124. **What is a reference?**  
    A reference is a pointer to an object. Java has four types: strong, soft, weak, phantom.

125. **What are strong, soft, weak, phantom references?**  
    Strong reference prevents GC. Soft reference cleared at GC's discretion (for memory-sensitive caches). Weak reference cleared at next GC (for canonical maps). Phantom reference not directly retrievable, used for post-mortem cleanup.

126. **What is a `WeakHashMap`?**  
    WeakHashMap uses weak references for keys; when a key is no longer referenced elsewhere, entry is automatically removed. Useful for caches.

127. **What is an `IdentityHashMap`?**  
    IdentityHashMap compares keys by reference (==) rather than equals(). Used in serialization, deep copies.

128. **What is a `LinkedHashSet`?**  
    LinkedHashSet maintains insertion order (doubly-linked list) while providing HashSet uniqueness. Slightly slower than HashSet.

129. **What is a `Deque`?**  
    Deque (double-ended queue) allows insertion/removal at both ends. Implementations: ArrayDeque, LinkedList.

130. **What is a `BlockingQueue`?**  
    BlockingQueue supports operations that wait for the queue to become non-empty or space to become available. Used in producer-consumer.

131. **What is the difference between `ArrayBlockingQueue` and `LinkedBlockingQueue`?**  
    ArrayBlockingQueue is bounded array-based; LinkedBlockingQueue optionally bounded, linked-node-based, higher throughput but more memory.

132. **What is a `ConcurrentMap`?**  
    ConcurrentMap extends Map with thread-safe operations (putIfAbsent, remove, replace). Implemented by ConcurrentHashMap.

133. **What is `ConcurrentHashMap`?**  
    ConcurrentHashMap is a thread-safe map with high concurrency, using bucket-level locking (or CAS) rather than whole map lock.

134. **What is a `CopyOnWriteArrayList`?**  
    CopyOnWriteArrayList is thread-safe; modification creates a new copy of underlying array. Best for read-heavy, infrequent write scenarios.

135. **What is a `CopyOnWriteArraySet`?**  
    Based on CopyOnWriteArrayList; thread-safe set for small sizes with few writes.

136. **What is a `SynchronousQueue`?**  
    SynchronousQueue has no capacity; each insert must wait for corresponding remove. Used for hand-off designs.

137. **What is a `PriorityQueue`?**  
    PriorityQueue orders elements based on natural order or comparator. Not thread-safe. Elements must be Comparable or comparator provided.

138. **What is a `DelayQueue`?**  
    DelayQueue holds Delayed elements; elements can only be taken after their delay has expired.

139. **What is a `TransferQueue`?**  
    TransferQueue (LinkedTransferQueue) allows producers to wait for consumers to receive elements (transfer method).

140. **What is a `Skip List`?**  
    A skip list is a probabilistic data structure allowing fast search within an ordered sequence. ConcurrentSkipListMap is a scalable concurrent map.

141. **What is a `StampedLock`?**  
    StampedLock (Java 8) supports three modes: write, read, and optimistic read. Optimistic read doesn't block but must validate stamp later.

142. **What is a `ReadWriteLock`?**  
    ReadWriteLock maintains separate locks for read (shared) and write (exclusive). Improves concurrency when reads > writes.

143. **What is the difference between `Lock` and `Semaphore`?**  
    Lock grants exclusive access to a resource. Semaphore permits multiple concurrent accesses (counting semaphore).

144. **What is the difference between `Lock` and `synchronized`?**  
    Lock (java.util.concurrent) provides more flexibility (tryLock, lockInterruptibly, fairness). synchronized is simpler, automatic release.

145. **What is a `CyclicBarrier`?**  
    CyclicBarrier allows a set of threads to wait for each other at a barrier point. After all arrive, optionally run a barrier action, then release. Can be reused.

146. **What is a `CountDownLatch`?**  
    CountDownLatch allows one or more threads to wait until a set of operations complete. Cannot be reused.

147. **What is a `Phaser`?**  
    Phaser is a more flexible barrier, can be dynamically registered/deregistered, reusable, and supports multiple phases.

148. **What is an `Exchanger`?**  
    Exchanger allows two threads to exchange objects at a rendezvous point.

149. **What is a `ForkJoinPool`?**  
    ForkJoinPool is a specialized ExecutorService for work-stealing, designed for parallel divide-and-conquer tasks (ForkJoinTask).

150. **What is work stealing?**  
    Work stealing is when idle threads steal tasks from busy threads' queues, improving load balancing. ForkJoinPool uses work stealing.

151. **What is the difference between ForkJoinPool and ExecutorService?**  
    ForkJoinPool uses work-stealing and is optimized for recursive tasks; ExecutorService is more general thread pool. ForkJoinPool extends ExecutorService.

152. **What is a `CompletableFuture`?**  
    CompletableFuture (Java 8) is a Future that can be manually completed, supports chaining, combining, and callbacks for async programming.

153. **What thread does a `CompletableFuture` use?**  
    By default, async methods use ForkJoinPool.commonPool() unless a custom Executor is provided.

154. **What is a `ThreadLocal`?**  
    ThreadLocal provides thread-local variables; each thread has its own independently initialized copy. Useful for context like request IDs.

155. **What's wrong with `ThreadLocal`?**  
    Memory leaks possible if thread continues to live (e.g., application servers) and values are not removed. Also can cause confusion in shared data.

156. **How can you avoid `ThreadLocal` memory leaks?**  
    Always call `remove()` when done, or use try-finally block. Use static inner classes to avoid accidental retention.

157. **What is a virtual thread?**  
    Virtual threads (Java 21) are lightweight threads managed by JVM, not OS. They allow high concurrency with simple blocking code, part of Project Loom.

158. **How expensive is a platform thread?**  
    Platform threads map to OS threads, expensive memory (stack ~1MB). Virtual threads have tiny footprint (few KB), can have millions.

159. **What is a blocking call?**  
    A blocking call causes the thread to wait until operation completes (e.g., I/O, lock acquisition). Virtual threads handle blocking by yielding.

160. **What is the difference between `Runnable` and `Callable`?**  
    Runnable's run() returns void and cannot throw checked exceptions. Callable's call() returns a value and can throw checked exceptions.

161. **What is the difference between `submit()` and `execute()`?**  
    execute() (Executor) runs task with no return. submit() (ExecutorService) returns Future representing pending result.

162. **What is `Future`?**  
    Future represents result of asynchronous computation. Methods: get() (blocking), cancel(), isDone(), isCancelled().

163. **What is `FutureTask`?**  
    FutureTask is a cancellable asynchronous computation, implements RunnableFuture, can be used with Executor or directly run.

164. **What is `AtomicInteger`?**  
    AtomicInteger provides thread-safe operations on an int using CAS (compare-and-swap). Part of java.util.concurrent.atomic.

165. **What is `LongAdder`?**  
    LongAdder (Java 8) is more efficient than AtomicInteger for high contention by reducing contention via striped counters.

166. **What is `Striped64`?**  
    Striped64 is the base class for LongAdder and LongAccumulator, maintaining a striped counter to reduce contention.

167. **What is `ThreadPoolExecutor`?**  
    ThreadPoolExecutor implements ExecutorService, configurable core pool size, max size, keep-alive time, work queue, rejection policy.

168. **What are the rejection policies?**  
    AbortPolicy (throws exception), CallerRunsPolicy (runs task in caller thread), DiscardPolicy (silently discards), DiscardOldestPolicy (discards oldest unprocessed task).

169. **What is `ScheduledThreadPoolExecutor`?**  
    ScheduledThreadPoolExecutor extends ThreadPoolExecutor to schedule commands to run after a delay or periodically.

170. **What is `TimeUnit`?**  
    TimeUnit is an enum representing time durations (e.g., SECONDS, MILLISECONDS). Used with concurrency utilities for timeouts.

171. **What is a lock?**  
    A lock is a synchronization mechanism to control access to a shared resource. In Java, intrinsic locks (synchronized) and explicit Locks.

172. **What is an object monitor?**  
    Each Java object has an associated monitor. It allows threads to synchronize via synchronized methods/blocks using wait/notify.

173. **What is `wait()` and `notify()`?**  
    wait() causes current thread to release the monitor and wait until notified. notify() wakes up one waiting thread on the same monitor.

174. **What is `notifyAll()`?**  
    notifyAll() wakes up all threads waiting on the monitor. They compete for the lock.

175. **What is a spurious wakeup?**  
    Spurious wakeup is when a waiting thread wakes without being notified. Always call wait() in loop checking condition.

176. **What is double-checked locking?**  
    Double-checked locking is a pattern to reduce overhead of synchronization by first checking condition without lock, then locking and checking again. In Java, need volatile field to prevent issues.

177. **What is `volatile`?**  
    volatile ensures visibility of changes across threads and prevents reordering. Reads always see latest write. Does not guarantee atomicity for compound actions.

178. **What does "happens-before" mean?**  
    Happens-before is a guarantee of memory visibility: if one action happens-before another, the first's results are visible to the second. Volatile, synchronized, thread start/join establish happens-before.

179. **What is the difference between concurrency and parallelism?**  
    Concurrency is dealing with multiple tasks at same time (interleaved). Parallelism is executing multiple tasks simultaneously (multicore).

180. **What is a race condition?**  
    Race condition occurs when outcome depends on timing/order of thread execution, leading to inconsistent results.

181. **What is deadlock?**  
    Deadlock is when two or more threads are blocked forever, each waiting for a resource held by another. Conditions: mutual exclusion, hold and wait, no preemption, circular wait.

182. **How to avoid deadlock?**  
    Avoid nested locks, use lock ordering with timeouts, use higher-level concurrency utilities.

183. **What is livelock?**  
    Livelock is when threads keep changing state in response to each other but no progress. They are not blocked but stuck.

184. **What is starvation?**  
    Starvation occurs when a thread never gets CPU time or access to resources because others monopolize them.

185. **What is thread safety?**  
    A class is thread-safe if it behaves correctly when accessed from multiple threads. Achieved by synchronization, immutability, thread-local storage.

186. **What is a thread scheduler?**  
    Thread scheduler decides which thread to run and for how long. Part of OS, but JVM can influence via thread priorities (not reliable).

187. **What is a parallel stream?**  
    Parallel stream uses ForkJoinPool to process elements concurrently. Obtained by `collection.parallelStream()` or `stream.parallel()`.

188. **Why do stateful operations not play well with parallel streams?**  
    Stateful operations (like sorted, distinct) require global coordination, reducing parallelism. They may need to merge results, causing overhead.

189. **What is a parallel-friendly stream source?**  
    Sources like ArrayList, arrays, IntStream.range are efficiently splittable; streams from LinkedList, files are less parallel-friendly.

190. **What is a spliterator?**  
    Spliterator is an iterator for traversing and partitioning streams. Supports splitting parts for parallel processing.

191. **What is the difference between `Iterator` and `Spliterator`?**  
    Iterator has next/hasNext. Spliterator also has trySplit to divide, characteristics (SIZED, ORDERED), and long-sized estimates.

192. **What is a `Gatherer`?**  
    Gatherer (Java 22 preview) is an intermediate operation that transforms a stream element-by-element, more flexible than map/filter.

193. **What is `mapMulti()`?**  
    mapMulti (Java 16) is like flatMap but uses consumer to push multiple elements, avoiding stream creation overhead.

194. **What is a distinct stream?**  
    distinct() is a stateful intermediate operation that removes duplicates based on equals(). In parallel, uses concurrent reduction.

195. **How does `Stream.distinct()` work?**  
    It internally uses a Set to track seen elements. For parallel streams, it uses ConcurrentHashMap for thread-safety.

196. **What is the difference between `map()` and `flatMap()`?**  
    map applies function and returns a Stream of results. flatMap returns a Stream of results after flattening nested structures.

197. **What is the difference between `findFirst()` and `findAny()`?**  
    findFirst returns first element (respects encounter order), findAny returns any element (non-deterministic, better for parallel).

198. **What is the difference between `reduce()` and `collect()`?**  
    reduce is for immutable reduction (combining values into single result). collect is mutable reduction (accumulating into container like list).

199. **How does the `reduce()` method work?**  
    reduce takes BinaryOperator and combines elements sequentially. It can have identity. Example: sum = stream.reduce(0, Integer::sum).

200. **How does the `collect()` method work?**  
    collect uses a Collector to accumulate elements into a result. Example: list = stream.collect(Collectors.toList()).

201. **What is a `Collector`?**  
    Collector is an interface that implements mutable reduction. It has supplier, accumulator, combiner, finisher, and characteristics.

202. **What are the parts of a `Collector`?**  
    supplier (creates container), accumulator (adds element), combiner (merges containers), finisher (optional final transform), characteristics (IDENTITY_FINISH, CONCURRENT, etc.)

203. **What is `Collectors.toList()`?**  
    Returns a Collector that accumulates input elements into a new List (ArrayList). Characteristics: IDENTITY_FINISH.

204. **What is `Collectors.toSet()`?**  
    Returns a Collector that accumulates elements into a new HashSet.

205. **What is `Collectors.toMap()`?**  
    Returns a Collector that accumulates elements into a Map. Requires keyMapper and valueMapper. Can handle duplicates with merge function.

206. **What is `Collectors.groupingBy()`?**  
    Groups elements by classifier function, returns Map<K, List<T>>. Can specify downstream collector and map supplier.

207. **What is `Collectors.partitioningBy()`?**  
    Partitions elements by Predicate into Map<Boolean, List<T>>. Two groups: true and false.

208. **What is `Collectors.mapping()`?**  
    Adapts a collector to accept elements after applying a mapping function. Used as downstream collector.

209. **What is `Collectors.joining()`?**  
    Concatenates input elements (CharSequence) into a String, optionally with delimiter, prefix, suffix.

210. **What is `Collectors.reducing()`?**  
    Returns a collector that performs reduction on elements using a BinaryOperator. Used as downstream.

211. **What is an intermediate `Collector`?**  
    Not standard; but collectors can be composed (e.g., groupingBy(mapping())) where downstream collectors are intermediate.

212. **Can you explain the parameterized types of a `Collector`?**  
    Collector<T, A, R>: T input type, A mutable accumulation type, R final result type. A is often internal (e.g., list, map).

213. **What is a `Stream`?**  
    Stream is a sequence of elements supporting sequential and parallel aggregate operations. Not a data structure; consumes from source.

214. **What is the difference between intermediate and terminal operations?**  
    Intermediate operations (map, filter) are lazy and return a new stream. Terminal operations (forEach, collect) produce result or side-effect and close stream.

215. **What is a stateless operation?**  
    Stateless operation like filter or map does not maintain state from previously seen elements. Can be processed independently.

216. **What is a stateful operation?**  
    Stateful operation like distinct, sorted, limit must remember previously seen elements, potentially affecting parallel performance.

217. **How does `dropWhile()` work?**  
    dropWhile returns a stream dropping elements that match predicate until first non-match; then includes the rest. For ordered stream, drops prefix.

218. **How does `takeWhile()` work?**  
    takeWhile returns a stream taking elements while predicate holds; stops at first mismatch. Opposite of dropWhile.

219. **What is the difference between `peek()` and `forEach()`?**  
    peek is intermediate operation intended for debugging; it performs action on each element as they flow. forEach is terminal.

220. **How can you limit a stream?**  
    limit(n) returns a stream truncated to no more than n elements. For parallel streams, may need to combine with unordered for speed.

221. **How can you skip elements in a stream?**  
    skip(n) discards first n elements. For parallel ordered streams, may be expensive.

222. **What is a stream builder?**  
    Stream.builder() creates a builder for adding elements and building stream. Use `accept()` and `build()`.

223. **How can you create an `Iterable` from a `Stream`?**  
    Convert to Iterable by `stream::iterator` but note stream can only be consumed once. Or collect to collection and then iterate.

224. **How can you create a `Stream` from an `Iterator`?**  
    Use `Spliterators.spliteratorUnknownSize(iterator, characteristics)` then `StreamSupport.stream()`.

225. **What is an `Optional`?**  
    Optional is a container object that may or may not contain a non-null value. Used to avoid null checks and NullPointerException.

226. **Why do you need `Optional`?**  
    To explicitly handle absence, reduce null checks, and compose functional operations. Not meant for fields or serialization.

227. **What are common `Optional` methods?**  
    isPresent(), ifPresent(), orElse(), orElseGet(), orElseThrow(), map(), flatMap(), filter().

228. **What is the difference between `orElse()` and `orElseGet()`?**  
    orElse() always evaluates the default value even if Optional is present. orElseGet() lazily evaluates the Supplier only when absent.

229. **What is a `MessageFormat`?**  
    MessageFormat is used to produce concatenated messages in a language-neutral way with placeholders like {0}. Supports pluralization and choice.

230. **What is a `PrintWriter`?**  
    PrintWriter prints formatted representations of objects to a text-output stream. Provides print, println, printf methods.

231. **What is a `ByteBuffer`?**  
    ByteBuffer is a buffer for bytes, used in NIO for reading/writing data. Can be direct (off-heap) or heap-based.

232. **What is a `CharBuffer`?**  
    CharBuffer is a buffer for characters, used with NIO and charset encoding/decoding.

233. **What is a `FileChannel`?**  
    FileChannel is a channel for reading/writing files, supports locking, mapping to memory, and transfer to/from other channels.

234. **How can you map a file to memory?**  
    Use FileChannel.map(MapMode.READ_ONLY, position, size) to get MappedByteBuffer for memory-mapped file I/O.

235. **What is off-heap memory?**  
    Off-heap memory is memory outside JVM heap (direct byte buffers). Reduces GC overhead, used for high-performance caches.

236. **How can you access off-heap memory?**  
    Use ByteBuffer.allocateDirect() or Unsafe (not recommended). From Java 22, Foreign Function & Memory API (MemorySegment) provides safe access.

237. **What is a `MemorySegment`?**  
    MemorySegment (Foreign Memory API) represents a contiguous region of memory, either on-heap or off-heap, with spatial and temporal bounds.

238. **What is a `MemoryLayout`?**  
    MemoryLayout describes the layout of a memory segment (size, alignment, element types) to enable structured access.

239. **What is a `VarHandle` in memory access?**  
    VarHandle can be used to access memory segments with relaxed or atomic operations, but for FFM, MemorySegment provides methods.

240. **What are the different kinds of Arenas?**  
    In Foreign Memory API, Arena controls lifetime of memory segments. Types: global, confined, shared, automatic (try-with-resources).

241. **What is a `Cleaner`?**  
    A Cleaner is used to perform cleanup actions when an object becomes phantom reachable. Used in DirectByteBuffer to free off-heap memory.

242. **What is a `Reference`?**  
    Reference is abstract base class for soft, weak, phantom references. Used with ReferenceQueue to track reachability changes.

243. **What is a `ReferenceQueue`?**  
    ReferenceQueue is where references are enqueued after their referent becomes appropriately reachable. Used for cleanup.

244. **What is the difference between `SoftReference` and `WeakReference`?**  
    SoftReference cleared at GC's discretion when memory is low. WeakReference cleared at next GC if referent has no strong refs.

245. **What is `PhantomReference`?**  
    PhantomReference's get() always returns null. It is used for post-mortem cleanup; referent is already dead.

246. **What is data alignment?**  
    Data alignment ensures that data is placed at memory addresses multiple of its size (e.g., int aligned to 4 bytes). Improves CPU access.

247. **What is an object header?**  
    Object header (mark word + klass pointer) contains metadata: hashcode, GC age, lock state, class pointer. In compressed oops, may be 12 bytes.

248. **What is scalarization?**  
    Scalarization is an optimization where JVM replaces an object allocation with its fields (scalars) if escape analysis proves object doesn't escape.

249. **What is escape analysis?**  
    Escape analysis determines if object references escape method or thread. Used for stack allocation, lock elimination, scalarization.

250. **What does tearing mean?**  
    Tearing is when a write to a variable is not atomic, causing partial updates visible to other threads. Use volatile or atomic for long/double.

251. **What is heap pollution?**  
    Heap pollution occurs when a variable of a parameterized type refers to an object not of that type, leading to ClassCastException at runtime.

252. **What is pinning?**  
    Pinning refers to preventing an object from being moved by GC (e.g., during native code access). Relevant in ZGC for colored pointers.

253. **What is a fail-safe iterator?**  
    Fail-safe iterator works on a snapshot/clone of collection, so modifications don't affect iteration. Example: CopyOnWriteArrayList iterator.

254. **What is a fail-fast iterator?**  
    Fail-fast iterator throws ConcurrentModificationException if collection is modified structurally after iterator creation. Most java.util collections.

255. **What is late binding?**  
    Late binding (dynamic binding) means method call resolved at runtime based on object type (polymorphism). Contrast with early binding (static).

256. **What is a non-denotable type?**  
    A type that cannot be named explicitly in Java code, e.g., intersection types, anonymous class types, or captured wildcards.

257. **What is a `SequencedCollection`?**  
    SequencedCollection (Java 21) defines a collection with a defined encounter order, offering methods like getFirst(), getLast(), reversed().

258. **What is a `SequencedMap`?**  
    SequencedMap (Java 21) extends Map with sequenced order, methods firstEntry(), lastEntry(), pollFirstEntry(), reversed().

259. **What is the difference between a Zip and a Gzip stream?**  
    Zip is an archive format (multiple files) with compression. Gzip is a compression format for single file, often used with tar.

260. **How can you read a ZIP file with the `FileSystem` API?**  
    Use FileSystems.newFileSystem(Path, ClassLoader) to create a FileSystem for ZIP, then access files via Path.

261. **How can you read a Gzip compressed file?**  
    Use GZIPInputStream to wrap FileInputStream. For text, wrap with InputStreamReader.

262. **How can you create temporary files?**  
    Files.createTempFile(prefix, suffix) or File.createTempFile(). They are deleted on JVM exit unless deleteOnExit set.

263. **How can you create a directory with Java I/O?**  
    Files.createDirectory(path) for single dir, Files.createDirectories(path) to create missing parents.

264. **How can you get the content of a directory?**  
    Files.list(path) returns Stream<Path>; Files.newDirectoryStream(path) returns DirectoryStream.

265. **How can you stream the content of a directory?**  
    Files.list() or Files.walk() returns Stream<Path> for walking recursively.

266. **How can you read chars from a binary stream?**  
    Use InputStreamReader to decode bytes to chars. Specify charset (e.g., StandardCharsets.UTF_8).

267. **How can you stream the content of a text file?**  
    Files.lines(path) returns Stream<String> of lines. Use with try-with-resources to ensure closing.

268. **What is the heap memory?**  
    Heap memory is where Java objects are allocated. Divided into young gen (eden, s0, s1) and old gen. Managed by GC.

269. **What is the heap memory structure?**  
    Young generation (eden + survivor spaces) for new objects. Old generation for long-lived objects. Permanent/Metaspace for class metadata.

270. **What is metaspace?**  
    Metaspace (Java 8+) replaces PermGen; stores class metadata. It uses native memory, dynamically resized.

271. **What is a Garbage Collector?**  
    GC automatically reclaims memory of unreachable objects. Types: Serial, Parallel, CMS, G1, ZGC, Shenandoah.

272. **How does G1 GC work?**  
    G1 divides heap into regions, concurrently marks live objects, and collects regions with most garbage first (garbage-first). Predictable pause times.

273. **What is ZGC?**  
    ZGC is a scalable low-latency GC (sub-millisecond pauses) using colored pointers and load barriers, handles large heaps.

274. **What is a stack trace?**  
    Stack trace shows the call stack at a point in time, listing methods and line numbers. Useful for debugging exceptions.

275. **When is a stack trace created?**  
    When an exception is thrown, or manually via Thread.dumpStack() or new Throwable().printStackTrace().

276. **What is the difference between `ClassNotFoundException` and `NoClassDefFoundError`?**  
    ClassNotFoundException is thrown when class not found dynamically (Class.forName). NoClassDefFoundError is when class was present at compile-time but missing at runtime.

277. **What is a `LinkageError`?**  
    LinkageError and subclasses indicate incompatible class changes (e.g., IncompatibleClassChangeError, NoSuchMethodError).

278. **What is an `OutOfMemoryError`?**  
    OutOfMemoryError occurs when JVM runs out of heap or native memory. Causes: memory leak, excessive allocations.

279. **What is a `StackOverflowError`?**  
    StackOverflowError when thread stack fills due to deep recursion or infinite recursion.

280. **What is an `ArrayIndexOutOfBoundsException`?**  
    Thrown when accessing array with illegal index (negative or >= length).

281. **What is a `NullPointerException`?**  
    Thrown when trying to access member (method/field) of a null reference.

282. **What is an `IllegalArgumentException`?**  
    Thrown to indicate a method has been passed an illegal/inappropriate argument.

283. **What is an `IllegalStateException`?**  
    Thrown when method called at inappropriate time (e.g., after stream closed).

284. **What is a `ConcurrentModificationException`?**  
    Thrown when collection modified during iteration (unless using concurrent collections).

285. **What is a `DateTime`?**  
    From Java 8, new Date/Time API (java.time) includes LocalDate, LocalTime, LocalDateTime, ZonedDateTime, etc. Immutable, thread-safe.

286. **How can you format a date?**  
    Use DateTimeFormatter. Example: LocalDate.now().format(DateTimeFormatter.ofPattern("dd/MM/yyyy")).

287. **How can you represent time?**  
    Use Instant (machine time), LocalDateTime (date+time without timezone), ZonedDateTime (with zone), OffsetDateTime (with offset).

288. **What is the epoch?**  
    Epoch is the reference point for time: 1970-01-01T00:00:00Z. Instant and many systems measure time as milliseconds from epoch.

289. **What is a `Duration`?**  
    Duration is a time-based amount (seconds, nanoseconds) between two temporal objects.

290. **What is a `Period`?**  
    Period is a date-based amount (years, months, days) between two dates.

291. **What is `java.util.Date` vs `java.time.LocalDate`?**  
    Date is mutable, poorly designed, deprecated. LocalDate is immutable, part of modern API, no time component.

292. **What is a `Calendar`?**  
    Legacy class for date manipulation, replaced by java.time. Prone to errors, mutable.

293. **How can you generate random numbers?**  
    Use Random (not thread-safe), ThreadLocalRandom (thread-safe), SecureRandom (cryptographic). Also Math.random().

294. **How can you compute the median value of an array?**  
    Sort array, then pick middle element(s). Use Arrays.sort() or priority queue for streaming.

295. **How is quick sort working?**  
    Quick sort picks a pivot, partitions array into smaller/larger, recursively sorts partitions. Average O(n log n).

296. **What is a `Skip List`?**  
    Skip list is a probabilistic data structure with multiple levels, allowing O(log n) search. Used in ConcurrentSkipListMap.

297. **What is a `WeakReference`?**  
    WeakReference objects are cleared by GC when referent is only weakly reachable. Used in WeakHashMap.

298. **What is a `SoftReference`?**  
    SoftReference cleared at GC's discretion when memory is low. Useful for memory-sensitive caches.

299. **What is a `PhantomReference`?**  
    PhantomReference's get() always null; enqueued when object is about to be reclaimed. Used for cleanup.

300. **What is a `Reference` queue?**  
    ReferenceQueue where references are enqueued after referent becomes appropriately reachable. Used for tracking cleanup.

301. **What is the difference between `HashMap` and `Hashtable`?**  
    HashMap is not synchronized, allows null keys/values. Hashtable is synchronized, does not allow nulls. Hashtable is legacy.

302. **What is the difference between `ArrayList` and `LinkedList`?**  
    ArrayList is resizable array, fast random access, slow insert/remove in middle. LinkedList is doubly-linked, faster insert/remove, slower access.

303. **What is the difference between `ArrayList` and `Vector`?**  
    Vector is synchronized (legacy), ArrayList not synchronized. Both use array; Vector doubles size, ArrayList grows by 50%.

304. **What is the difference between `HashSet` and `TreeSet`?**  
    HashSet uses hash table (O(1)), unordered. TreeSet uses tree (O(log n)), sorted. LinkedHashSet maintains insertion order.

305. **What is the difference between `HashMap` and `TreeMap`?**  
    HashMap O(1), unordered. TreeMap sorted by keys (natural or comparator), O(log n). LinkedHashMap maintains insertion/access order.

306. **How does a `HashSet` work?**  
    HashSet internally uses HashMap; elements are stored as keys with a dummy value. Relies on hashCode() and equals().

307. **How does `HashMap` work?**  
    HashMap uses array of buckets; each bucket may be linked list or tree. Keys' hashCode() determines bucket index. Handles collisions with chaining.

308. **What is the initial capacity and load factor of `HashMap`?**  
    Default initial capacity 16, load factor 0.75. Rehashes when size > capacity * load factor.

309. **What is the difference between fail-fast and fail-safe iterators?**  
    Fail-fast throws ConcurrentModificationException if modified. Fail-safe (copy-on-write) iterates over snapshot.

310. **How does `Map.keySet()` method work?**  
    Returns a Set view of keys; changes to map reflect in set. Not a separate copy.

311. **How does `Map.values()` method work?**  
    Returns a Collection view of values; reflects map changes.

312. **What is an entry set?**  
    entrySet() returns Set<Map.Entry<K,V>>, allowing iteration over key-value pairs.

313. **What is `getOrDefault()`?**  
    Map.getOrDefault(key, defaultValue) returns value mapped to key, or defaultValue if absent.

314. **What is `putIfAbsent()`?**  
    putIfAbsent(key, value) puts value only if key not already mapped. Returns existing value or null.

315. **What is `computeIfAbsent()`?**  
    computeIfAbsent(key, mappingFunction) computes value if key absent and adds to map; returns computed or existing value.

316. **What is `computeIfPresent()`?**  
    computeIfPresent(key, remappingFunction) recomputes value if key present; if result null, removes entry.

317. **What is `merge()`?**  
    merge(key, value, remappingFunction) combines value with existing using function; if absent, puts value; if function returns null, removes.

318. **What is the difference between `Collection` and `Collections`?**  
    Collection is root interface. Collections is utility class with static methods (sort, synchronized, unmodifiable).

319. **What are the interfaces in Collections Framework?**  
    Collection, List, Set, Queue, Deque, Map (not extend Collection). Also SortedSet, NavigableSet, SortedMap, NavigableMap.

320. **What is the difference between `Iterator` and `Enumeration`?**  
    Iterator has remove() and is fail-fast. Enumeration is legacy, has moreElements/nextElement, no remove.

321. **What is the difference between `Array` and `ArrayList`?**  
    Array is fixed size, can hold primitives and objects. ArrayList is dynamic, only objects (wrappers for primitives). ArrayList provides more methods.

322. **What is the difference between `List` and `Set`?**  
    List allows duplicates, ordered. Set no duplicates, unordered (unless sorted). List has positional access.

323. **What is the difference between `Queue` and `Deque`?**  
    Queue typically FIFO, offer/poll/peek. Deque supports insertion/removal at both ends.

324. **What is a `PriorityQueue`?**  
    PriorityQueue orders elements by priority (natural/comparator), not FIFO. Head is least element.

325. **What is a `BlockingQueue`?**  
    BlockingQueue adds thread-safe operations that block (put/take). Implementations: ArrayBlockingQueue, LinkedBlockingQueue.

326. **What is a `ConcurrentSkipListMap`?**  
    A concurrent, sorted map using skip list. Supports higher concurrency than TreeMap.

327. **What is a `ConcurrentSkipListSet`?**  
    Concurrent sorted set based on ConcurrentSkipListMap.

328. **What is a `LinkedBlockingDeque`?**  
    Optionally bounded deque with blocking operations, linked nodes.

329. **What is the difference between `synchronized` and `java.util.concurrent` locks?**  
    synchronized is built-in, automatic unlock. Lock interface gives explicit lock/unlock, tryLock, interruptible, fairness.

330. **What is a `Semaphore`?**  
    Semaphore maintains a set of permits, used to limit concurrent access to a resource.

331. **What is a `CountDownLatch`?**  
    CountDownLatch allows threads to wait until count reaches zero. Cannot be reset.

332. **What is a `CyclicBarrier`?**  
    CyclicBarrier allows threads to wait for each other; after all arrive, optionally run a barrier action, then reset.

333. **What is a `Phaser`?**  
    Phaser is a flexible barrier that can be reused with dynamic number of parties.

334. **What is an `Exchanger`?**  
    Exchanger allows two threads to exchange objects at a rendezvous.

335. **What is a `ForkJoinTask`?**  
    Abstract base for tasks executed in ForkJoinPool. Subclasses: RecursiveAction, RecursiveTask.

336. **What is `RecursiveTask`?**  
    RecursiveTask is a ForkJoinTask that returns a result. Must implement compute().

337. **What is `RecursiveAction`?**  
    RecursiveAction is a ForkJoinTask that returns no result (void).

338. **What is the common pool?**  
    ForkJoinPool.commonPool() is a shared pool used by parallel streams and CompletableFuture.

339. **What is a `ThreadPoolExecutor`?**  
    ExecutorService implementation with configurable core/max pool size, queue, rejection policy.

340. **What is a `ScheduledExecutorService`?**  
    ExecutorService that can schedule commands to run after a delay or periodically.

341. **What is a `Callable`?**  
    Functional interface with call() returning value and throwing checked exceptions. Used with ExecutorService.submit.

342. **What is a `Future`?**  
    Represents result of async computation; can check if done, cancel, and get result.

343. **What is a `CompletableFuture`?**  
    Future that can be manually completed, supports callbacks, chaining, and combining.

344. **What is `thenApply()` and `thenCompose()`?**  
    thenApply transforms result (like map). thenCompose returns a new CompletableFuture (like flatMap).

345. **What is `thenAccept()`?**  
    thenAccept consumes result with Consumer, returns CompletableFuture<Void>.

346. **What is `exceptionally()`?**  
    exceptionally recovers from exception with a fallback value.

347. **What is `handle()`?**  
    handle processes both result and exception, returns a new result.

348. **What is `allOf()` and `anyOf()`?**  
    allOf returns CompletableFuture that completes when all given CompletableFutures complete. anyOf completes when any completes.

349. **What is a `Latch`?**  
    Generally refers to CountDownLatch.

350. **What is a `CyclicBarrier`?**  
    Already defined.

351. **What is a `ReadWriteLock`?**  
    Lock with separate read and write locks. Multiple readers, one writer.

352. **What is a `StampedLock`?**  
    Introduced in Java 8, supports optimistic reads. Has methods to validate stamps.

353. **What is the difference between `synchronized` and `Lock`?**  
    synchronized simpler, auto-release. Lock offers tryLock, lockInterruptibly, fair queue, multiple conditions.

354. **What is a `Condition`?**  
    Condition associated with Lock, provides await/signal instead of wait/notify. Can have multiple conditions per lock.

355. **What is a `ReentrantLock`?**  
    A Lock implementation with same basic behavior as synchronized but more features. Reentrant: same thread can acquire multiple times.

356. **What is a `ReentrantReadWriteLock`?**  
    Implements ReadWriteLock; both read and write locks are reentrant.

357. **What is a `ThreadFactory`?**  
    Factory to create new threads. Used by Executors to customize thread creation.

358. **What is a `ThreadGroup`?**  
    Represents a group of threads; can manage them collectively. Not as useful now; ExecutorService preferred.

359. **What is a `Thread`?**  
    A thread of execution in a program. In Java, can be created by extending Thread or implementing Runnable.

360. **What is the difference between `start()` and `run()`?**  
    start() creates new thread and calls run(). run() just executes in current thread.

361. **What is a `daemon` thread?**  
    Daemon threads are low-priority threads that run in background (e.g., GC). JVM exits when only daemon threads remain.

362. **What is thread interruption?**  
    Interrupt is a cooperative mechanism to signal a thread to stop. Threads should check interrupted status.

363. **How to stop a thread?**  
    Use a volatile boolean flag. Thread.stop() is deprecated and unsafe.

364. **What is `Thread.yield()`?**  
    yield hints scheduler that current thread is willing to yield CPU. Not guaranteed to do anything.

365. **What is `Thread.sleep()`?**
